# Level 10 Enchantments 1.5.0

## Acquisition rebalance

- Removed all VI-X outcomes from enchanting tables.
- Kept the 25-bookshelf, level-50 enchanting setup; it now only improves the
  chance of vanilla maximum-level and multi-enchantment results.
- Equal-level anvil combinations only upgrade within the original vanilla
  range. At or above the vanilla maximum, equal levels merge without
  increasing; the higher level still covers the lower level.
- Added independent VI-X promotion rolls for every existing enchantment on
  generated loot equipment and books in the approved structure sources.
- Added one independent extra high-level book roll per approved container.
  High-level equipment and the extra book may appear together.
- Added one persistent, restockable B2 high-level enchanted-book trade to every
  master librarian.
- Restricted Soul Speed VI-X to bastion loot and Wind Burst VI-X to ominous
  trial vaults. Neither is available from librarians.

## Client polish

- Replaced the saturated per-character rainbow and binary font-weight wave with
  a slower, gamma-corrected aurora gradient.
- Removed bold flicker from level-X enchantment names.

## Compatibility

- Minecraft `26.1.2`
- Fabric Loader `0.19.3+`
- Fabric API `0.146.1+`
- Java `25+`
